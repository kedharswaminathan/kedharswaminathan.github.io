Nintendo Game Reception Prediction

Can you predict a game's critic reception before it's released?

How I approached it

Using 1,094 Nintendo games scraped from Metacritic, I asked whether characteristics known before release (platform, genre, developer, ESRB rating, and release year) predict whether critics score a game above the median of 77.

The first version reported 82% accuracy, and it was wrong. A typo in the list of columns to drop (meta_scores instead of meta_score) was hidden by a setting that suppresses errors, so the critic score stayed in the features and the model was reading the answer. Separately, 385 games with no critic score had all been labeled "not successful," so a third of the labels described nothing.

I rebuilt the pipeline: removed games with no score or no release (706 remain), split genre lists so each genre gets its own column, and dropped the player score as too close to the answer. The feature set went from 3,421 columns to 51.

What I found

The honest model scores about 0.72 ROC-AUC against a 0.50 coin-flip baseline. Three different algorithms land within a few hundredths of each other, which suggests that's close to the ceiling for this kind of data. Most of what makes critics like a game, such as execution, polish, and writing, isn't captured by a genre label.

What this doesn't show

  • One train/test split with default settings. Cross-validation would give steadier estimates.
  • About 140 test games is a small sample, so small differences between models shouldn't be read into.
  • Splitting at the median is arbitrary: a 76 and a 78 aren't meaningfully different games.
  • A genre that's associated with higher scores doesn't make a game better.
